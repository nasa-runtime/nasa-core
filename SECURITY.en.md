# Security policy

[中文](SECURITY.md) | [English](SECURITY.en.md)

## Supported scope

Security maintenance covers the latest published version. Existing Maven Central artifacts cannot be replaced;
security updates require a new patch version.

## Reporting vulnerabilities

Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/nasa-runtime/nasa-core/security/advisories/new).
Include affected versions, impact, reproduction conditions, and suggested mitigation. Do not open a public issue or
disclose directly exploitable details before the security update is available.

Maintainers assess the impact, prepare an update, and coordinate disclosure. Use GitHub Issues for ordinary defects
and feature requests.
